Настройка проекта

Подключение папки не запускает задания. Команда проверок применяется к новым шаблонам.

Задания

Новые задания создаются на паузе. Приёмку решают проверки и ревью, а не перетаскивание карточек.

Команда

За столами — шаги сценария и их модели, документы — задания. Клик по стопке открывает задание, по столу — шаг.

Создать на паузе

Задание начнёт работу только после продолжения и запуска очереди.

Сценарии

Публикация создаёт неизменяемую версию. Уже созданные задания остаются на своей версии.

успех сбой и возврат гейт

«+» на стрелке вставляет шаг. Кружок справа от шага начинает связь: затем выберите целевой шаг. Выбранную связь удаляет Delete.

Агенты и лимиты

Вход выполняется в родном CLI; ключи сюда не вводятся. Имя профиля — это обработчик, на который ссылаются шаги: профили claude и codex делают шаблоны исполнимыми.

Бюджет очереди

Это предел числа запусков за всю историю базы, не прогноз стоимости подписки. Зарезервированные вызовы учитываются, даже если CLI завершился ошибкой. Проверки и ответы человека вызовы не расходуют.
